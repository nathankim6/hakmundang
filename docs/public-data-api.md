# 공공데이터 API 레퍼런스

2026-09-01 직접 호출로 검증. 설계 문서는 `docs/school-selection-design.html`.

## 1. 학교알리미 공시 API

```
GET https://www.schoolinfo.go.kr/openApi.do
    ?apiKey={키}&apiType={NN}&schulKndCode=04&sidoCode=11&sggCode=11590&pbanYr=2026
```

| 항목 | 값 |
|---|---|
| 필수 파라미터 | `apiKey`, `apiType`, `schulKndCode` (대부분 항목은 `pbanYr`도 필수) |
| 선택 파라미터 | `sidoCode`, `sggCode` |
| 학교급 코드 | 02 초 / **03 중** / **04 고** / 05 특수 / 06 그외 / 07 각종 |
| 지역 코드 | 서울 `sidoCode=11` · **동작구 `11590`** · **송파구 `11710`** (`/download/sido_sggCode.xlsx`) |
| 조회 가능 연도 | **2024 · 2025 · 2026** (특례법 시행령상 3년 롤링 삭제) |
| 응답 | JSON — `resultCode` / `resultMsg` / `list` |
| 호출 제한 | 없음 · 적재주기 연 1회 |
| 라이선스 | 공공누리 제1유형(출처표시, 영리·가공·2차저작물 허용) |
| 학교코드 | `S` + 9자리 (예: 숭의여고 `S010000482`) — NEIS 코드와 직접 조인 불가 |

**`apiKey=sample`이 실제로 동작하며 응답은 20행에서 잘린다.** 개발·검증용으로 충분하고 운영에는 발급키 필요.
인증키 발급: <https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_m1.do> → 구글/카카오/페이스북/트위터 로그인 → 사용자 구분 + 사용목적 등록 → 즉시 발급.

### API에 없는 공시항목

공시항목은 55종인데 API는 35종. 빠진 것 중 중요한 것:

| 코드 | 항목 | 대안 |
|---|---|---|
| `15` | **교과별 학업성취 사항** (영어 성취도 A~E) | 확보 불가 → 학원이 수기 입력 |
| `52` | **졸업생의 진로 현황** (4년제 진학률) | 아래 2번 경로로 확보 가능 |
| `05` | 학교교육과정 편성·운영 및 평가 | 웹 열람 |
| `14` | 교과별 교수·학습 및 평가계획 (서술형 비중 원본) | 웹 열람 |
| `83` / `57` / `81` | 교과진도 운영계획 · 입학전형 요강 · 고교 Profile | 웹 열람 |

EDSS(에듀데이터서비스)는 학술연구 목적 + 정보공개심의회 심의라 학원은 사실상 이용 불가.

## 2. 진로현황 — 공개용데이터 내부 경로

```
POST https://www.schoolinfo.go.kr/openData.do
  APIKEY=schoolinfo2020&APITYPE=52&SCHULKNDCODE=04&PBANYR=2025&LCTNSCCODE=01
```

- **`DEPTHNO`를 넣으면 실패한다.** 빼야 동작.
- 시도 단위 전량 반환 — 서울 고교 283건. `LCTNSCCODE` 서울=01, 경기=10.
- `APITYPE=0·62·10`도 같은 경로로 전량 반환(서울 고교 319~324건) → 20행 제한 우회.
- 2026년분 진로현황은 **2026-12-01 공개**.
- 문서화되지 않은 내부 경로이므로 보조 수단으로만 사용.

응답 필드 (검증: `TOT_SUM = TOTAL3+TOTAL4+TOTAL5+TOTAL6` 283/283 일치)

| 필드 | 의미 |
|---|---|
| `TOTAL2` | 졸업자 |
| `TOTAL3` | 전문대 진학 |
| `TOTAL4` | 4년제 대학교 진학 |
| `TOTAL6` | 국외진학 |
| `TOTAL7` | 취업자 |
| `TOTAL8` | 기타(재수 등) |
| `TOT_SUM` / `TOT_SUM_RATE` | 진학자 계 / 진학률(%) |

**공시 오류 주의.** 잠실여고 2025년 공시는 전문대 38.2% / 4년제 14.7%인데 2024년은 14.0% / 42.6%다. 학교가 두 칸을 뒤바꿔 입력한 것으로 보인다. 전년 대비 급변 감지를 반드시 넣을 것.

## 3. NEIS 교육정보 개방포털

```
GET https://open.neis.go.kr/hub/{서비스명}?KEY={키}&Type=json&pIndex=1&pSize=1000
```

- 서비스 12종: `schoolInfo`, `hisTimetable`/`misTimetable`/`elsTimetable`/`spsTimetable`, `SchoolSchedule`(S 대문자), `mealServiceDietInfo`, `classInfo`, `schoolMajorinfo`, `schulAflcoinfo`, `tiClrminfo`, `acaInsTiInfo`
- **인증키 없으면 `pIndex`가 1로 고정되고 5행만 반환**된다. 페이징되는 것처럼 보이니 주의. 오류코드 `ERROR-290`.
- 갱신 **매주** · `pSize` 상한 1000 (`ERROR-336`) · 일별 트래픽 초과 `ERROR-337`
- 인증키 발급: <https://open.neis.go.kr> → 구글/네이버/다음 로그인 → 활용가이드 → 인증키 신청 → **즉시 발급**

### 시간표에서 개설 과목 추출

```
GET /hub/hisTimetable?ATPT_OFCDC_SC_CODE=B10&SD_SCHUL_CODE=7010204&AY=2026&SEM=1&ALL_TI_YMD=20260511
→ ITRT_CNTNT = "공통영어1"
```

- 과목명에 **분반 접미**가 붙는다: 영등포고 3학년 `심화 영어ⅠF`, `영어 독해와 작문D`. 정규화 필요.
- 시간표가 비어 있는 학교·학년이 산발적으로 있다(숭의여고 1학년). 결손을 "미개설"로 오독하지 말 것.

### 학교코드 (NEIS `SD_SCHUL_CODE`, 서울 `ATPT_OFCDC_SC_CODE=B10`)

| 학교 | NEIS | 학교알리미 |
|---|---|---|
| 숭의여자고등학교 | `7010204` | `S010000482` |
| 성남고등학교 | `7010193` | `S010000468` |
| 영등포고등학교 | `7010098` | `S010000497` |
| 당곡고등학교 (관악구·자율고) | `7010073` | — |

두 코드 체계는 직접 조인되지 않는다. 학교명 + 도로명주소로 매칭한 매핑 테이블을 유지할 것.

## 5. 보안

`.env`가 git에 추적되고 있고 `.gitignore`에 없다. **API 키는 `.env.local`에 둘 것** (`*.local` 규칙으로 제외됨). 운영에서는 Supabase Edge Function이 키를 쥐고 프록시한다 — Vite의 `VITE_` 변수는 빌드 결과물에 그대로 박힌다.
