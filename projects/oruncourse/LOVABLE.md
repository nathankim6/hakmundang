## 실행 방법

```sh
npm install
npm run dev
```

잠금 파일(package-lock.json, bun.lock, bun.lockb)은 가져오지 않았습니다. 위 `npm install`이 새로 만듭니다.

## 가져오지 못한 파일

배포된 사이트에서 찾을 수 없어 비어 있습니다. "코드에서 사용" 표시가 없는 파일은 앱이 쓰지 않는 파일이라 없어도 됩니다. 사용 중인 파일은 Lovable 편집기에서 내려받아 같은 자리에 넣으면 됩니다.
