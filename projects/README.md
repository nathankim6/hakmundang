# Lovable 프로젝트 모음

Lovable에서 만든 프로젝트들을 코드 그대로 이 폴더 아래에 하나씩 옮겨 두었습니다. 폴더마다 `LOVABLE.md`에 출처(Lovable 편집기 주소, 배포 주소, 데이터베이스 종류)와 가져오지 못한 파일이 적혀 있습니다.

## 알아 둘 것

- 이 사본들은 Lovable과 **자동으로 동기화되지 않습니다.** Lovable에서 계속 고치면 여기 사본은 옛것이 됩니다. 앞으로는 이 폴더에서 고치세요.
- 잠금 파일(package-lock.json, bun.lockb)은 가져오지 않았습니다. 각 폴더에서 `npm install` 하면 새로 만들어집니다.
- 데이터베이스가 "내 Supabase"인 앱은 그대로 동작합니다. "Lovable Cloud"인 앱은 Lovable 구독이 있는 동안 동작하고, 완전히 독립하려면 창고를 옮겨야 합니다. 방법은 안내서 4단계 경우 B를 보세요.
- 이미 GitHub과 동기화되는 세 프로젝트는 여기에 복사하지 않았습니다. 각자 자기 레포에서 고치세요.
