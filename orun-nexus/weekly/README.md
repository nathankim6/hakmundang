# ORUN WEEKLY VOL.1 — 주차별 학습지 20개

옳은영어 주간지 `for Top/고1` VOL.1 을 **한 주차 = 한 파일**로 끊은 HTML 20개.
`out/ORUN_WEEKLY_VOL1_WEEK01.html` … `WEEK20.html`. 인터넷 없이 열리고
브라우저에서 그대로 A4로 인쇄된다.

## 한 파일에 들어 있는 것

| 구획 | 내용 |
|---|---|
| 표지 | WEEK 번호 · 문장/어법/어휘/해설 수 |
| STUDY GUIDE | 학습 방법 6항 (인쇄 문구 그대로) |
| 핵심 어휘 | 그 주의 어휘 전량 (번호 · 단어 · 품사 · 뜻) |
| 단어 시험 | 50문항씩 2회분, 뜻 칸은 비워 둠 |
| 본문 100문장 | 어법 이름표 + 영문 + 우리말, 문장마다 접었다 펴는 ORUN GUIDE 해설 |
| 정답 | 그 주 100문항, 정답지 원문 그대로 |

해설(ORUN GUIDE)은 문장마다 **오류 수정 / 오답 분석 / 구문 분석 ①②③…** 세 칸이다.
해설 지면이 없는 문장에는 정답만 접어 넣는다.

## 실물에서 확인한 수치

원본 PDF 8개(750면) 전수 파싱 결과 — 교재가 스스로 밝힌 수치와 전부 일치한다.

- 문장 : 15개 주차 × 100문장
- 어휘 : 주차 첫 장의 `VOCABS` 값과 15/15 일치 (323·160·150·163·206·142·232·218·261·209·224·190·294·217·199)
- 단어 시험 : 주차마다 100문항
- 정답 : 1,921문항 (목차의 「총 문장 수 1,921」과 일치)
- ORUN GUIDE 해설 : 909문장분 (1~11주차, 교재에 실린 만큼)

16~20주차는 제공된 PDF에 목차와 정답지만 있어 정답 100·100·100·100·21문항만 싣고
본문 미확보를 파일 안에 명시한다.

## 정답 검증

`verify2.py` — 정답지 1,921건의 '고치기 전' 표현이 실제 본문에 있는지 대조.
`verify3.py` — 정답지 ↔ 해설집 대조.

- 본문에서 확인 : 1,483건 그대로 + 12건(사이에 부사가 끼어 인용이 줄어든 자리)
- 정답지 ↔ 해설집 일치 : 905건 중 891건(98.5%), 나머지 14건도 인용 범위 차이일 뿐 정정 내용은 같음
- 실제로 어긋난 자리 4건은 `gen_week_html.py` 의 `ERRATA` 에 적어 해당 주차 정답 위에 표시한다
  (5주차 47·62번, 10주차 56번, 12주차 96번)

## 다시 만들기

```bash
node extract2.mjs                 # PDF 8개 → weekly_raw4.json (좌표까지 보존)
WEEKLY_RAW=weekly_raw4.json python3 parse_weekly.py   # → weekly.json
WEEKLY_RAW=weekly_raw4.json python3 parse_guide.py    # → guide.json
python3 gen_week_html.py                              # → out/*.html 20개
```

`weekly_raw4.json`(6.5MB)은 원본 PDF의 중간 산출물이라 저장소에 두지 않는다.

### 줄바꿈 복원 (`wrapjoin.py`)

이 교재의 우리말은 낱말 한복판에서도 줄이 바뀐다. 그래서 PDF 줄을 공백으로 이으면
`여전히`가 `여 전히`가 되고, 공백 없이 이으면 `들어오지 않았다`가 `들어오지않았다`가
된다. 줄 끝 공백은 CSS 에서 매달려(hanging) 줄 폭에 들어가지 않고 PDF 에도 남지 않아
기하로는 두 경우를 가를 수 없다.

그래서 **교재 자체를 사전으로** 쓴다. 750면에서 한 줄 안에 온전히 찍힌 낱말을 모아 두고,
두 조각을 붙인 꼴이 그 목록에 있으면 낱말 한복판에서 잘린 것, 두 조각이 각각 낱말로
있으면 공백에서 잘린 것으로 판별한다. 같은 낱말이 책 어딘가에서는 한 줄에 온전히 찍혀
있기 때문에 이 판별이 선다. 로마자 경계와 닫는 부호 뒤는 언제나 공백이다.

결과: 우리말 텍스트 5,958건에서 잘못 붙은 덩어리 0건, 잘못 갈라진 자리 0건
(남은 후보 20건은 `한 번`·`또 한`·`그 다음`처럼 원래 띄어 쓴 자리).
