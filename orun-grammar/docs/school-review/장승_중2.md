# 장승_중2 검수 기록 (200문항 전수 검수)

## 수정 건수 (총 12문항)
- 정답 오류: 0건 (개수 세기 27문항·조합형 9문항 전부 한 문장씩 재검산, 불일치 없음)
- 복수 정답·오답 근거 불명확: 7건 (33, 65, 86, 96, 109, 126, 200)
- 선택지 구성 오류(논리적으로 불가능한 선택지): 1건 (22)
- 중복·유사 소재: 4건 (49, 139, 158, 193)
- 영문 오류 0 / 한국어 오탈자 0 / 카테고리 불일치 0 / 조건-정답 불일치 0 / 학교 유형 불일치 0

## 대표 수정 예
1. 96번: 오답으로 둔 `Our team have observed ~`가 영국식 집합명사 복수 취급으로 성립 가능 → 주어를 `Dr. Kim`으로 바꿔 3인칭 단수 수일치만 묻도록 정리.
2. 109번: ⓐ `She had no one help her.`가 have+O+원형(사역)으로 성립 → ⓐ를 정문으로 돌리고 ⓔ `I have no time wasting.`을 오류 항목으로 교체(정답 `ⓔ / wasting → to waste`).
3. 22번: 제시문이 7문장인데 선택지에 `8개`가 있어 성립 불가 → 선택지를 2~6개로 재구성하고 정답 번호를 4개(③)로 조정.
   그 밖에 86번 `has gone to ~ twice`(미국식 경험 용법 허용), 200번 `Give me something to write.`(그대로도 성립), 126번 `books read in the library`(과거분사 후치수식으로 읽힘)를 명확한 오류문으로 교체.

## 남은 우려
- 학교 유형(개수 세기·(A)~(E) 어법 판별·★ 배열·ⓐ~ⓕ 조합·to 빈칸)은 모두 반영됐으나, 원자료의 서답형 0문항 기조와 달리 101~200이 서답형이라 실제 시험지 비율과는 다름(세트 규격상 불가피).
- `a desk to study` / `a partner to dance` / `a brush to paint`처럼 전치사를 남기는 함정은 이 학교 기출(`a chair to sit`)과 동일 계열이라 유지했으나, 원어민 감각으로는 완전 비문이라기보다 어색한 수준인 문장이 일부 있음.
- 현재완료·to부정사 형용사적 용법에 소재가 집중되어(m2-05 75 / m2-07 57) 유사 문장 재활용이 많음. 학교 출제 범위 자체가 좁아 의도된 반복으로 판단.
