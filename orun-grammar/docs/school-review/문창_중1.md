# 문창중 중1 검수 보고
검수 문항 200(mc 1~100 / short 101~200) 전부 1문항씩 정독. `python3 validate.py gen/문창_중1.json` → **OK**.
개수 세기 8문항(7·20·33·45·57·69·82·95)은 10문장씩 직접 다시 세어 정답 전부 일치. 4형식↔3형식 전치사(to/for/of)는 동사별로 전수 검산(give/send/show/lend/tell/bring/pass/teach/sell/write→to, make/buy/cook/get/find/build→for, ask→of) — 오류 0건. 밑줄 기호 ⓐ~ⓔ 본문·선택지 대조(mc 16 + 짝짓기 3 + short 8) 불일치 0건.
## 수정 건수 (총 11건)
정답 오류 0 / 복수 정답 소지 1(65) / 영문 오류 0 / 한국어 오탈자 0 / 카테고리 불일치 0 / 조건-정답 불일치 0 / 중복·유사 문항 5(20·59·126·129·131·163 중 문장 중복 교체) / 발문·렌더링 오류 7(10·25·41·59·75·90 없는 밑줄 지시, 167) / 해설 보완 2(40·53). ※59는 두 항목 중복 집계.
## 대표 수정 예
1. 65번 ①"When the phone rang, I was taking a shower."는 어법·의미가 모두 옳아 정답 ④와 복수 정답이 됨 → "When we were playing soccer, the rain starts."(과거 상황에 현재형)로 교체하고 해설 재작성.
2. 10·25·41·59·75·90번 발문 "밑줄 친 부분을 ~ 바꾼 것은?"은 본문에 밑줄 표시가 없어 지시가 성립하지 않음 → "주어진 문장을 ~ 바꾼 것은?"으로 수정(167번 "밑줄 친 부분"도 "보어"로 명시).
3. 131번 표(Sora 150/Mina 160, 정답 "Mina is taller than Sora.")가 58번 표(Mina 155/Sora 162)와 사실이 충돌 → Yuna 150/Bora 160으로 교체. 그 밖에 2번↔126·129번, 7번↔163번, 13번↔20번, 59번↔146번의 동일 영어 문장 중복도 각각 새 문장으로 교체.
## 남은 우려
- 원본(2학기 기말)에 서답형이 전혀 없어(전 문항 OMR) short 100문항의 조건 문구는 일반 내신 관례를 따랐다. mc 100문항은 analysis의 mc_formats(전환문 ⟹ 판별, ⓐ~ⓔ 밑줄, 비교급·최상급 형태/표 묘사, 동명사 목적어 빈칸, 조동사 고쳐 쓰기, 개수 세기)를 모두 반영.
- cat 분포(m1-16 54/m1-12 36/m1-10 36/m1-17 28/m1-08 18/m1-05 18/m1-09 10)는 analysis 가중치를 따랐고 m1-08(There is/are)은 원본 21번의 종합 판별 문항을 대체한 것이다.
- "(수여동사의 3형식 전환 3)", "(2)" 같은 괄호 번호가 발문 아래 남아 있다. 동일 발문 구분용이라 유지했으나 실제 시험지로 낼 때는 지우는 것이 자연스럽다.
- 최상급 오답으로 쓴 fun-funner(85), ill-illest(63)는 교과서 관례상 more fun / worst가 정답이라는 전제에 기대고 있다.
