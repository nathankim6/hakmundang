# 신길중 중1 검수 보고
검수 문항 200(mc 1~100 / short 101~200) 전부 1문항씩 정독. `python3 validate.py gen/신길_중1.json` → **OK**(카테 6, 상60/중80/하60, 정답분포 1:20 2:21 3:20 4:20 5:19).
어법 밑줄형 91문항(ⓐ~ⓔ 79 + (A)~(E) 9 + 대화 ⓐ~ⓔ 3)은 ① 발문 줄을 제외한 본문에 ⓐ~ⓔ/(A)~(E)가 **각각 정확히 1회**씩 있는지, ② 선택지가 ⓐ~ⓔ 순서인지 기계 점검(이상 0건) → 밑줄 기호 누락·불일치 없음. 공통 접속사형 7문항도 본문 (A)·(B) 각 1회 확인.
"의도한 오류가 한 곳뿐인가"는 오류 유형별 정규식으로 455개 밑줄 문장을 전수 스캔했다(감각동사+부사 / more+-er / There is+복수·are+단수 / because of+절 / when·if절+will / because~so / V+what+완전절 / 접속사+주어없음 / 동명사동사+to-v / to부정사동사+v-ing / 전치사+동사원형 / 원급+than / 감각동사+like+형용사). 검출된 오류는 **전부 해당 문항의 정답 위치와 일치**했고, 정답 아닌 밑줄에서 우발적 오류는 나오지 않았다(오검출은 "There are a lot of people", "about the sea", "more difficult than" 등 정상 문장뿐).
조건 영작 30문항은 조건의 "총 N단어"와 모범답안 단어 수를 기계 대조 → **30/30 일치**(4·5·6·7·8·9·11단어). <보기> 항목도 전부 사용됐고 변형은 조건이 허용한 be→is/are/was, go→went, write→writing, make→made, cannot→could not, ride→Riding 뿐이었다. 표 비교 7문항은 수치 방향(더 큰/작은 쪽)까지 대조 → 오류 0.

## 대표 수정 예
1. **72번 복수 정답 소지** — (C) "the most quiet place"를 오답으로 지목했으나 `most quiet`은 실제 영어에서 허용되는 형태라 "어법상 어색"하다고 단정할 수 없다 → **the most quietest**(most와 -est 병용)로 교체하고 해설도 이중 최상급 설명으로 수정. 정답 ③ 유지.
2. **49·81·94번 영문 부자연** — "say that the beautiful lights and music." / "says that the power of small questions." / "say that the road along the river."처럼 that 뒤에 명사구만 남긴 문장은 학생이 무엇이 빠졌는지 알기 어렵고 81번은 187번과 사실상 같은 문장이었다 → "Everyone agrees that the night view very beautiful." / "says that small questions very important." / "Many people believe that the new road very useful."(be동사 누락)로 바꾸고 해설도 함께 수정. 78번 ⓔ "taste like sweetly"(이중 오류)는 전형적 함정인 "taste like sweet"로 교체.
3. **4·87·139·173·185번 중복** — 4번 ⓔ가 137번 정답 문장과 동일("The baby looks like a little angel.") → "The little puppy looks like a toy."로 교체. 87번 ⓑ "The singer's voice feels warm."(부자연) → "The concert hall feels warm.", ⓔ의 비유는 47번과 겹쳐 "like a sweet dream"으로 변경. 119·139·173번은 <보기>가 셋 다 `when, because, that`이고 정답까지 (a)When (b)because (c)that로 동일 → 139번은 순서를 when/that/because로 바꾸고, 173번은 <보기>를 `if, because, that`으로 바꿔 조건절 현재시제까지 묻도록 지문을 다시 썼다. 185번은 163번과 첫 대사("My dream is (a)")가 같아 "I hope (a) ____ someday."로 교체.
## 남은 우려
- 학교 유형 반영은 충실하다. analysis 의 mc_formats 4종이 그대로 배분됐고(밑줄 어법 91 / 공통 접속사 7 / 그림 대조 There is·are 2), cat 분포(m1-17 75 / m1-10 38 / m1-09·m1-11·m1-16 각 25 / m1-08 12)는 cat_weights(3 : 1.5 : 1 : 1 : 1 : 0.5)와 정확히 비례한다. 신길 원본의 배점·부분점수(문장당 1점)는 스키마상 표현하지 않았다.
- m1-17이 75문항이라 오류 유형이 반복될 수밖에 없다(when·if절+미래 9, because of+절 6, what→that 5, because~so 4, 콤마 접속 4, 주어 없는 when절 3, that절 동사 누락 4). 발문·소재·인명은 모두 다르지만 같은 함정이 시험지 안에서 재등장하는 인상은 남는다.
- 31·64·96·197번의 comma splice는 원어민 기준 "문장부호 오류"에 가까워 채점 시 "접속사 누락"으로 안내하는 편이 낫고, 서답형 "표를 보고 비교하는 말 완성하기" 7문항은 analysis 의 short_formats 에 없는 형태다(원본은 그림 기반 비교급 영작 — 그림 대신 표로 옮기고 조건 문구는 원본 스타일을 따랐다).
