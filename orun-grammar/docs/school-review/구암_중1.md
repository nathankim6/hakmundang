# 구암중 중1 검수 보고
검수 문항 200(mc 1~100 / short 101~200) 전부 1문항씩 정독. `python3 validate.py gen/구암_중1.json` → **OK**.
개수 세기 16문항(5·10·13·22·23·34·39·41·52·61·66·73·78·89·90·94)은 문장별로 다시 세어 정답 전부 일치. 밑줄 기호 스크립트 검사(ⓐ~ⓔ 56 / ⓐ~ⓓ 10 / ⓐⓑ 빈칸 14 / 계획표 ⓐ~ⓔ 8)에서 본문 누락·정답 기호 불일치 0건.
## 수정 건수 (총 9건)
정답 오류·문항 불성립 2(62·64) / 복수 정답 소지 1(100) / 조건-정답 불일치 1(116) / 영문 오류·어색 2(62 lemon ade→lemonade, 170) / 발문·형식 오류 3(110 주어 누락, 146 없는 밑줄 지시, 159 빈칸 표기) / 중복·유사 1(188). 한국어 오탈자·카테고리 불일치·학교 유형 불일치 0건. ※62는 두 항목 중복 집계.
## 대표 수정 예
1. 62번 ⓒ "It is only ten minutes from my house to the market."는 어법상 옳아 정답(③)이 성립하지 않음 → "ⓒThere was only ten minutes ~"(비인칭 주어 It 오류)로 교체, 해설 재작성.
2. 64번 ⓔ "He never stops to learn ~"은 stop+to-v(~하려고 멈추다)로 읽으면 옳아 오류로 단정 불가 → "He never gives up to learn ~"(give up+v-ing 위반)으로 교체.
3. 116번 "Read comic books in the dark are bad ~"는 오류가 Read·are 두 곳이라 "틀린 부분 하나" 조건과 충돌 → are를 is로 바꿔 오류를 한 곳으로 정리.
## 남은 우려
- 학교 유형 반영은 충실(밑줄 판별·개수 세기·ⓐⓑ 짝짓기·계획표 대조·it 지시대상). 다만 원본에 서답형이 없어 서답형 100문항 조건 문구는 일반 내신 관례를 따랐다.
- cat 분포(m1-10 62/m1-11 46/m1-02 31/m1-15 31/m1-06 15/m1-04 15)는 analysis 가중치 비율 그대로 유지했으나, 계획표 대조 3문항(71·98·100)은 m1-04로 볼 여지도 있다.
- 감각동사(부사→형용사)와 -thing+형용사 어순 오류가 각 20여 회 반복. 문장·소재는 전부 다르지만 출제 포인트 반복도는 높은 편.
