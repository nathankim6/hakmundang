# 국사봉중 중2 검수 기록 (200문항 전수 정독, 수정 10건)
검수: mc 1~100·서답형 101~200 전 문항. 개수 세기 30문항은 문장별 재검산, for/since 26문항은 for·since 가능 여부 개별 확인 → 정답 오류 0건.
- 정답 오류 0 / 카테고리 불일치 0 / 한국어 오탈자 0 / 학교 유형 불일치 0 (cat m2-05 90·m2-07 60·m2-02 20·m1-16 20·m1-02 10, analysis 가중치·형식과 일치)
- 정답 노출·복수 정답 위험 3건: #82(오답 선택지와 그 교정문이 함께 제시), #90·#95(개수 세기 문항에 틀린 문장과 교정문이 쌍으로 포함) → 선택지·문장 교체(정답 번호 유지)
- 영문 오류·부자연스러움 3건: #73 'has never begun a new diary in January'(현재완료+과거시점 충돌) 교체, #88 'has grown strawberries many times' 교체, #4 'kept a hamster many times' → 'for two years'
- 조건-정답 불일치 1건: #102 제시어 (a friend)를 못 살린 정답 → "He doesn't have a friend to play with. / He has no friend to play with." 병기
- 정답 불명확 1건: #157 질문이 table/corner 두 답을 허용 → "What kind of corner ~"로 한정
- 어색한 현재완료 1건: #126 'has done ~ since' → 지문·정답을 'has worked on the recycling project since last spring'으로 정비
- 중복 문항 1건: #37에서 something+형용사 오류가 같은 형식에 3회 중복 → 학교 기출 포인트 'a new pen to write'로 교체
대표 수정 3건: (1) #90 'This bag is lighter ~'/'more light ~' 쌍 제거해 문장 2개 교체(정답 3개 유지) (2) #102 정답 병기 (3) #157 질문 한정으로 정답 유일화
남은 우려
- 'a desk to study / a room to study'처럼 전치사가 빠진 문장은 목적의 to부정사로도 읽혀 원어민 기준 논란 여지가 있으나, 학교 기출(③ Could you lend me a pen to write? = 어색)의 채점 관행을 그대로 따랐다.
- for/since 서답형은 '~ago' 9문항만 ' / '로 병기, 나머지 17문항(in 2015·last spring 등)은 since 단독이 유일 정답임을 확인.
- 개수 세기·밑줄 찾기 형식이 전체의 28%로 반복되나 학교 기출 비중을 반영한 의도적 편성이다.
