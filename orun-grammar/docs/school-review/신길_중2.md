조합형 40문항(12~21·62~71 = <보기>(a)~(e)/(a)~(g) 짝짓기, 22~31·72~81 = 지문 (A)~(E) 짝짓기)은 항목을 하나씩 O/X 판정해 '바른 것' 3개 또는 '틀린 것' 2개가 정확히 한 선택지에만 대응하는지 확인 → 복수 정답 0건. 어구 배열 N번째 칸 12문항(45~50·95~100)은 완성 문장을 만들어 칸을 세어 대조 → 정답 오류 0건. <보기> 단어 영작 26문항은 조건 단어 수 = <보기> 개수 = 모범답안 단어 수를 기계 대조(변형 허용 have→has, be→is, tell→told만 발생)했고 전부 일치.

1. 75번 (E) "She gave me a piece of cloth to practice."는 to practice on 이 필요한지가 모호해 오답 근거가 약함 → "to practice on it"(목적어 중복 오류)으로 교체하고 해설도 함께 수정. 정답 ①(C)(E)는 유지.
2. 145번 표 항목 learn the violin → play the violin. "has learned the violin since 2019"는 원어민 어감상 어색(계속 용법에 부적합) → "Sua has played the violin since 2019."
3. 183번 "I began to read this novel last week. I am still reading it." → 현재완료 계속으로 옮기면 "have read ~ since"가 부자연스러움 → "My uncle became a firefighter in 2015. He is still a firefighter." / 답 "My uncle has been a firefighter since 2015."로 교체. 195번은 23·76번과 소재(a bag to carry the books in)가 겹쳐 "a box to keep the tools in"으로 교체.
## 남은 우려
- 학교 유형 반영은 충실: analysis 의 mc 5유형이 그대로 배분됐다(㉮㉯ 용법 비교 22 / 조합 짝짓기 20 / (A)~(E) 틀린 것 모두 20 / 독립 5문장 어법 26 / 어구 배열 12). 다만 신길 원본 13·22번의 "[정답 2개] 모두 고르시오"는 스키마상 단일 정답이어야 해 전부 조합형 선택지로 바꿔 실었다(정답 수가 곧 힌트가 되는 원본 함정은 재현되지 않음).
- short 100문항은 analysis 의 short_formats 가 비어 있어(원본 서답형 미수록) 신길 mc 함정(과거표현+현재완료, 남는 전치사, -thing+형용사+to-v, 불규칙 과거분사, 최상급 철자)을 서답형 6유형으로 옮겨 구성했다. 실제 신길 서답형 양식과 다를 수 있다.
- 41·160번의 "to not worry / to not skip"은 현대 영어에서 완전히 비문은 아니나 내신 관례상 not to-v가 표준 답이라 오류 항목으로 두었다. 채점 시 유의.
- cat 분포(m2-05 67 / m2-07 56 / m2-02 22 / m1-16 22 / m1-18 22 / m1-08 11)는 analysis 가중치(m2-05 3, m2-07 2.5, m2-02·m1-16·m1-18 1, m1-08 0.5)를 그대로 따른다. 소재가 현재완료·to부정사에 몰려 있어 chair/paper/something 계열 소재가 반복되는 인상은 남는다(선택지·발문은 모두 상이).
