# 옳은문법 ORUN GRAMMAR — 문법 문제은행

2022 개정 교육과정 기준 중1·중2·중3·고등(공통영어1·2) 문법 문제은행과
시험지 생성·응시·성적 리포트를 하나의 HTML 파일로 제공한다.

## 규모

| 학년 | 문법 항목 | 문항 |
|---|---:|---:|
| 중1 | 18 | 3,600 |
| 중2 | 19 | 3,800 |
| 중3 | 22 | 4,400 |
| 고등 | 26 | 5,200 |
| 계 | **85** | **17,000** |

항목마다 200문항 — 객관식 140(선지 ①~⑤ 5개) + 주관식 60, 난이도 하68·중66·상66.
전 문항 해설(why) 포함.

## 파일

- `옳은문법.html` — 배포용 단일 파일. 브라우저로 열면 바로 동작한다(서버 불필요).
- `site.html` — 템플릿. `__BANK__` 자리에 문제은행이 주입된다.
- `bank/taxonomy.json` — 85개 문법 항목 분류(학년·항목명·핵심 포인트).
- `bank/<id>.json` — 항목별 200문항.
- `bank/textbooks.json` — 학년별 출판사 교재 52종의 단원↔문법 항목 매핑.
- `bank/orun.json` — 옳은영어 자체 교재(초등 9권 · 중등 11권)의 완성 시험지.
- `bank/parts/` — 생성 시 쓰인 부분 파일(하/중/상 × 객관식/주관식).
- `merge_bank.py` — 부분 파일 병합 + 규격 검증(문항 수·난이도 배분·선지 5개·stem 중복 등).
- `build_site.py` — `bank/*.json` 을 `site.html` 에 심어 `옳은문법.html` 생성.

## 기능

1. **문제은행** — 학년 → 카테고리 → 난이도·유형 필터, 정답/해설 토글.
2. **시험지 만들기**(교사) — 범위 다중 선택, 난이도, 객관식·주관식 문항 수 지정 →
   A4 인쇄(문제지 / 문제지+정답해설지), **학생 응시 코드**(`OG2.…`) 발급.
3. **학생 응시** — 코드 입력으로 동일 시험 응시, 또는 범위를 직접 골라 자유 연습.
   제출 시 자동 채점(주관식은 대소문자·문장부호·축약형 등 표기 변형 허용).
4. **성적 리포트** — 점수, 난이도별·카테고리별 정답률, 취약 항목 보완 추천,
   오답 해설, 인쇄.
5. **응시 기록** — 브라우저(localStorage)에 누적.

## 문항 데이터 형식

```json
{"no":1,"level":"하|중|상","type":"mc","stem":"...","choices":["…"],"answer":1,"why":"…"}
{"no":2,"level":"상","type":"short","stem":"...","answer":"…","alt":["…"],"why":"…"}
```

`stem` 안에서 빈칸은 `____`, 밑줄 강조는 `<u>…</u>` 만 사용한다.

## 문항 추가·수정

1. `bank/parts/<id>_p1..p6.json` 을 고치거나 새로 쓴다.
2. `python3 merge_bank.py <id>` — 규격 검증 후 `bank/<id>.json` 갱신.
3. `python3 build_site.py` — `옳은문법.html` 재생성.
